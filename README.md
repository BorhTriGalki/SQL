# SQL
Этот репозиторий хранит сделанные мною проекты буткемпа SQL в Школе 21.

**Project_1**
В этом проекте я создавал SQL-запросы с использованием внутренних подзапросов в частях FROM и SELECT, а также фильтровал данные по диапазону дат. Работал с условиями выборки, сортировкой по нескольким полям с разными направлениями и структурированием запросов для получения нужной информации.

**Project_2**
В этом проекте осваивал основные навыки работы с SQL: использование множеств и операторов объединения, создание подзапросов, сортировку по нескольким столбцам, а также разные виды соединений таблиц.

**Project_3**
В этом проекте продолжил осваивать основные навыки работы с SQL и реляционными базами данных: понимание реляционной алгебры, использование различных типов соединений (JOIN), создание запросов с помощью CTE, обработку пропущенных значений, фильтрацию и сортировку данных.

**Project_4**
В этом проекте научился извлекать данные из базы с помощью сложных SQL-запросов и изменять их при помощи языка управления данными (DML) — вставлять, обновлять и удалять записи для поддержания актуальности базы.

**Project_5**
В этом проекте научился создавать и использовать представления (views) для фильтрации данных, генерировать временные диапазоны и находить пропущенные даты, работать с операциями над множествами, рассчитывать скидки и управлять материализованными представлениями, включая их обновление и удаление.

**Project_6**
В этом групповом проекте применил SQL-инструменты для решения классической задачи коммивояжёра (Traveling Salesman Problem). Освоил навыки моделирования графов и маршрутов в SQL, научился создавать таблицы с узлами и стоимостью перемещений, а также писать запросы для поиска оптимальных путей с минимальными затратами и анализа результатов с сортировкой.

**Project_7**
В этом проекте освоил продвинутые техники работы с индексами PostgreSQL: научился создавать разные типы индексов, анализировать запросы и оптимизировать их так, чтобы все работало максимально быстро.

**Project_8**
В этом проекте научился реализовывать бизнес-требования, обеспечивать целостность данных через ограничения и индексы, оптимизировать производительность БД, работать с последовательностями и массовыми операциями, а также документировать структуру базы

**Project_9**
В этом проекте освоил ключевые практические навыки SQL-анализа, необходимые для решения реальных бизнес-задач: агрегацию данных (расчет сумм, средних, минимума/максимума), группировку по атрибутам, фильтрацию результатов, соединение таблиц и работу с условиями.

**Project_10**
В этом проекте изучил работу транзакций и уровней изоляции в PostgreSQL: воспроизвел классические аномалии данных (Lost Update, Dirty Reads и др.), проанализировал механизм взаимоблокировок (deadlock) и научился управлять согласованностью данных в параллельных процессах.

**Project_11**
В этом проекте освоил создание функций (SQL/PLpgSQL) и триггеров для реализации бизнес-логики на уровне СУБД, научился разрабатывать систему аудита изменений данных и оптимизировать запросы.

**Project_12**
В этом групповом проекте разобрался, как устроены хранилища данных (DWH). Создал SQL-запросы, которые умеют обрабатывать «неидеальные» данные: искать пропущенные значения, связывать информацию из разных источников и корректно агрегировать показатели.
